## 🚀 QUICK START

### 5-Minute Setup
```bash
cd Roam_MyWay

# Backend
cd backend
npm install
# Create .env with MongoDB URI and Gemini API key
npm run dev

# Frontend (new terminal)
cd frontend
npm install
npm run dev
```

Then:
- Open http://localhost:5173 (frontend)
- Backend API: http://localhost:5000/api
