## 🚀 QUICK START (5 MINUTES)

```bash
# 1. Create directories (use create_dirs.bat on Windows)
cd Roam_MyWay

# 2. Copy backend files from BACKEND_PART1-5.md to backend/src/
# 3. Copy frontend files from FRONTEND_PART1-8.md to frontend/src/

# 4. Install dependencies
cd backend && npm install
cd ../frontend && npm install

# 5. Create .env (copy from .env.example)
cd ../backend
# Edit .env with MongoDB URI and Gemini API key

# 6. Start servers
npm run dev

# Terminal 2:
cd frontend
npm run dev
```

Then visit: http://localhost:5173
